# ✦ Neon Gallery

A modern and responsive image gallery built as part of my **CodeAlpha Frontend Development Internship**.

The project combines HTML, CSS, and JavaScript to create an interactive visual gallery with category filtering, lightbox viewing, keyboard navigation, animations, and responsive design.

## 📌 Features

- ✦ Modern dark-themed interface
- 💎 Cyan `#00FFFF` accent design
- 🖼️ Responsive image gallery
- 🔍 Category-based image filtering
- 💡 Interactive image hover effects
- 🔦 Fullscreen lightbox
- ◀️ Previous / Next image navigation
- ⌨️ Keyboard navigation
- `←` Previous image
- `→` Next image
- `ESC` Close lightbox
- 📱 Responsive design for mobile, tablet, and desktop
- ✨ Smooth animations and transitions
- 🖼️ Local image assets
- ♿ Semantic HTML and accessible image alt text
